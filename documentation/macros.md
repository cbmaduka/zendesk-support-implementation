# Macros

## Business Requirement

To improve agent productivity and ensure consistent customer communication, reusable macros were created for common support scenarios.

## Macros Configured

- Close and redirect to topics
- Customer not responding
- Downgrade and inform
- Returns/Refunds
- Take it!

## Business Value

These macros reduce repetitive typing, improve response consistency, speed up ticket handling, and help agents follow standardized support procedures.
