# Knowledge Base Configuration

## Business Requirement

Gochelicious required a self-service knowledge base to reduce repetitive support requests and provide customers with instant access to frequently requested information.

## Knowledge Base Articles Created

The Help Center was populated with customer-facing articles covering common support topics, including:

- How to Check Order Status
- Shipping and Delivery Information
- Return Policy
- Refund Timeline
- Size Exchange
- Payment Methods
- VIP Membership
- Corporate Orders
- Cancel an Order
- Contact Customer Support

## Business Value

The knowledge base enables customers to resolve common questions independently, reducing ticket volume and improving response efficiency. It also provides agents with consistent reference material when responding to customer enquiries.
